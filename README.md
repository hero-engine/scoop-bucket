# hero-engine scoop bucket

[Scoop](https://scoop.sh) bucket for the Hero CLI on Windows.

## Install

```powershell
scoop bucket add hero-engine https://github.com/hero-engine/scoop-bucket
scoop install hero
```

## Source

Manifests in this repo are auto-generated on each Hero release by
[GoReleaser](https://goreleaser.com). Source lives in the (private)
`hero-engine/hero` repo; release artifacts in `hero-engine/hero-releases`.
